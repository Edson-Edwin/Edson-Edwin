# 8. Repository Structure (VERY IMPORTANT)

Every project repository should contain:

```text

.gitignore

```

# 10. Learn Git Properly

```bash
git init

git add .
git commit -m "message"
git push
git pull
git branch
git checkout
git merge
```

Advanced later:

```bash
git rebase
git stash
git cherry-pick
```
